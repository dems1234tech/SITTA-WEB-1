# SITTA - Sistem Informasi Transaksi & Tracking Bahan Ajar

SITTA adalah aplikasi berbasis web yang dirancang untuk mengelola stok, transaksi, dan pelacakan pengiriman bahan ajar di lingkungan Universitas Terbuka. Aplikasi ini mengusung desain premium dengan fitur lengkap yang memudahkan unit kerja (UPBJJ) dalam memantau distribusi buku secara real-time.

## ✨ Fitur Utama

- **Dashboard Interaktif**: Ringkasan stok, status pengiriman, dan aktivitas terkini.
- **Manajemen Stok**: Informasi detail bahan ajar lengkap dengan cover buku dan indikator stok kritis.
- **Keranjang Pesanan**: Sistem checkout dengan kalkulasi biaya otomatis dan cetak struk digital.
- **Tracking Pengiriman**: Pelacakan nomor DO/Resi dengan timeline perjalanan paket secara real-time.
- **Histori Transaksi**: Rekapitulasi pesanan yang terfilter berdasarkan akun pengguna (Unit/UPBJJ).
- **Manajemen Bahan Ajar**: Fitur tambah/hapus bahan ajar serta upload cover secara manual.

## 🚀 Teknologi yang Digunakan

- **HTML5 & Semantic HTML**
- **CSS3 (Vanilla)**: Menggunakan variabel, flexbox, grid, dan glassmorphism.
- **JavaScript (ES6)**: Logika aplikasi, state management menggunakan `localStorage`, dan interaksi real-time.
- **FontAwesome**: Untuk library ikon yang kaya.
- **Google Fonts**: Menggunakan font Inter dan Cinzel untuk kesan profesional.

## 📸 Tampilan Aplikasi

Aplikasi ini didesain agar terlihat modern dan premium dengan skema warna Universitas Terbuka (Biru & Kuning).

## 🛠️ Cara Menjalankan Secara Lokal

1. Clone repositori ini atau unduh file ZIP-nya.
2. Buka folder proyek di editor teks (seperti VS Code).
3. Jalankan file `index.html` menggunakan **Live Server** atau cukup buka langsung di browser.
